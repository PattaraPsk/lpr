# License Plate Reader (LPR)

Repository for Thai License Plate Reader and dataset annotation tools.

## Tools

- [`tools/`](tools): Desktop GUI application for inspecting, annotating, and reviewing Thai License Plate datasets following the structure:
  `{name}_{plate_type}_{d3}_{d4}_{province}.jpg`.
  See [`tools/README.md`](tools/README.md) for usage and instructions.
